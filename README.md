# noah_ssl_unpacker
诺亚舟ssl词典/搜学格式文件提取器
<img width="1115" height="628" alt="image" src="https://github.com/user-attachments/assets/4223a12d-3311-4588-8301-5c7df94987f9" /><img width="1149" height="786" alt="image" src="https://github.com/user-attachments/assets/edec0e57-cc80-41f3-8ffe-6b02e992d0d5" />

此脚本可以将诺亚舟特有的ssl格式文件进行解压操作，以便进行研究或再修改。
注：因诺亚舟对ssl文件的使用没有明确标准，目前只针对NP1500的百科搜学和古典诗词进行了测试，如发现有部分文件无法解压或有异常请反馈给我。
